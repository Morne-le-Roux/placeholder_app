# 🪦 Placeholder(Sunsetted)

> This repository contains the code for **Placeholder**, a Flutter application that has officially been **sunsetted**. Gone but not forgotten.

## 🧠 What was this?

Placeholder App was a **Flutter-based family productivity app** aimed at helping households manage day‑to‑day tasks through a **centralized dashboard**, accessible from **multiple phones**.

The idea was simple:

* One shared source of truth for the family
* Everyone sees the same tasks, updates, and status
* No more “I didn’t know that was my job” energy

It focused on coordination, visibility, and reducing household chaos.
